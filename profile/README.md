---

Cartograph is building a set of products for the people who run Minecraft servers: Listing,
Vitals, Logbook and more, all sharing one picture of your server. None of them have launched
yet. In the meantime, this is where the open-source pieces live.

- [**cartograph-plugin**](https://github.com/cartographgg/cartograph-plugin): the Cartograph
  telemetry plugin.
- [**minecraft-slp**](https://github.com/cartographgg/minecraft-slp): a PHP client for Server
  List Ping.
- [**minecraft-nbt**](https://github.com/cartographgg/minecraft-nbt): a PHP reader and writer
  for NBT.
- [**minecraft-text**](https://github.com/cartographgg/minecraft-text): a PHP parser and
  renderer for Minecraft chat text.
